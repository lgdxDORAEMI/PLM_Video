QR 데모 페이지 배포 방법

1. 이 폴더의 index.html, demo.mp4, poster.jpg를 같은 위치에 유지합니다.
2. GitHub Pages / Netlify / Cloudflare Pages 등 정적 호스팅에 업로드합니다.
3. 발급된 https://... 주소를 QR 코드의 URL로 사용합니다.
4. 이 페이지는 영상만 재생하므로 실제 서비스의 고정 계정/DB와 분리되어 있습니다.

GitHub Pages 예시
- 새 저장소 생성
- 세 파일을 저장소 루트에 업로드
- Settings > Pages > Deploy from a branch > main / root 선택
- 발급된 Pages URL을 QR에 연결

주의
- demo.mp4 파일명을 바꾸면 index.html의 <source src="demo.mp4">도 같이 변경해야 합니다.
